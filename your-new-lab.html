Shape Neighbor

Adjust a rectangle and find its nearest labeled example. This classroom demonstration uses numeric width and height. It is not image recognition.

All shapes use the same scale: 1 dimension unit = 2 screen pixels. The viewing areas stay the same size.

2. Compare the four reference examples

Each example has a fixed label: Horizontal or Vertical. Every equally nearest example is outlined and marked “Nearest.”

Distances are shown to two decimal places. Smaller means closer, not a confidence percentage. Predictions use unrounded distances.

How the prediction works

For each example, calculate the Euclidean distance:

distance = √((width − example width)² + (height − example height)²)

Choose the label of the nearest example. If multiple nearest examples share a label, use that label. If their labels differ, show “Tie”: both classes are equally close.

The prediction comes from these four examples and their distances, rather than a direct comparison of width and height.
